# Ночник (Nightlight)

**Ночник** — учебное WPF-приложение, демонстрирующее применение **контрактного программирования** (Design by Contract) для управления умным ночником. Пользователь выбирает операцию, вводит параметры, а программа проверяет **предусловия (pre)** и **постусловия (post)** до и после выполнения операции.

## Возможности

- Управление состоянием ночника через графический интерфейс:
  - включение;
  - выключение;
  - настройка яркости (0–100%);
  - настройка цвета (`Warm white`, `Cold white`, `White`).
- Для каждой операции заданы предусловия и постусловия.
- Проверка контрактов в реальном времени:
  - перед выполнением операции проверяется предусловие;
  - после выполнения проверяется постусловие;
  - результат отображается цветными индикаторами: зелёный — успех, красный — ошибка.
- Динамическое построение панели параметров в зависимости от выбранной операции:
  - чекбокс наличия питания;
  - ползунок яркости;
  - выпадающий список цветов.
- Кнопка **«Контракт»** показывает описание pre- и post-условий выбранной операции.
- Обработка исключений контроллера с выводом понятного сообщения пользователю.
- Заготовка операции «Таймер» присутствует в списке, но полноценный UI для неё пока не реализован.

## Как пользоваться

1. Запустите приложение.
2. В левой панели **«Операции»** выберите нужную операцию:
   - «Операция 1: Включение»;
   - «Операция 2: Настройка яркости»;
   - «Операция 3: Настройка цвета»;
   - «Операция 5: Выключение».
3. В правой панели появится карточка операции и элементы управления для ввода параметров.
4. При необходимости нажмите кнопку **«Контракт»**, чтобы посмотреть предусловия и постусловия выбранной операции.
5. Задайте параметры:
   - для включения — отметьте наличие питания;
   - для яркости — переместите ползунок;
   - для цвета — выберите цвет из списка.
6. Нажмите **«Выполнить»**.
7. Посмотрите результаты в нижнем блоке:
   - **Предусловие** — выполнено или ошибка;
   - **Постусловие** — выполнено или ошибка;
   - **Результат** — итоговый статус операции.

## Архитектура решения

Проект разделён на WPF-приложение и библиотеку с логикой предметной области.

| Компонент | Назначение |
|-----------|------------|
| `MainWindow.xaml` | Разметка главного окна: левая панель операций, правая панель карточки, параметров и результатов |
| `MainWindow.xaml.cs` | Логика окна: обработка выбора операции, динамическое создание элементов управления, проверка контрактов, обработка кнопок «Выполнить» и «Контракт» |
| `Library/NightlightController.cs` | Контроллер ночника: методы `TurnOn`, `TurnOff`, `SetBrightness`, `SetColor`, `SetTimer`, `TickSecond`; выбрасывает исключения при нарушении условий |
| `Library/NightlightState.cs` | Состояние ночника: `isOn`, `Brightness`, `currentColor`, `TimerMinutes`, `isTimerActive` |

Общий поток выполнения операции:

1. Пользователь выбирает операцию в `OperationsListBox`.
2. `OperationsListBox_SelectionChanged` очищает панель параметров и создаёт нужные элементы управления.
3. Пользователь нажимает **«Выполнить»**.
4. `Run_Click` вызывает соответствующий обработчик (`Run_On`, `Run_Set`, `Run_Color`, `Run_Off`).
5. Обработчик проверяет предусловие.
6. При успешной проверке вызывается метод `NightlightController`.
7. После выполнения проверяется постусловие.
8. Результаты отображаются через `PreWork` / `PreDontWork` и `PostWork` / `PostDontWork`.

## Сборка и запуск

### Требования

- Windows;
- Visual Studio с поддержкой WPF **или** установленный .NET SDK;
- целевая платформа — WPF-приложение под .NET / .NET Framework.

### Через Visual Studio

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/nightlight.git
   ```
2. Откройте файл решения (`.sln`) в Visual Studio.
3. Нажмите **F5** для сборки и запуска.

### Через командную строку

1. Перейдите в папку проекта:
   ```bash
   cd nightlight
   ```
2. Соберите проект:
   ```bash
   dotnet build
   ```
3. Запустите приложение:
   ```bash
   dotnet run
   ```

> Если проект использует .NET Framework, сборка и запуск выполняются через Visual Studio или MSBuild.

## Пример контракта

**Операция «Включение»**

- *Pre:* питание есть, свет выключен.
- *Post:* свет включён; если яркость была 0 — устанавливается 50; если яркость была настроена ранее — сохраняется.
